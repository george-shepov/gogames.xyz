Qualification first. Rewards second.

Skyline Sprint records a local qualifier badge when a non-demo run meets the time and damage rules. It also emits a structured browser event for future server integration. That event is not itself proof of a win.

Real-value GGX rewards stay disabled until the platform verifies the seed, input timeline or replay, account, age, location, anti-cheat checks, contest rules, and wallet transaction on the server.
1. Server signs the challenge seed.
2. Client records inputs and checkpoints.
3. Server replays and validates the run.
4. Eligibility rules decide the reward.
